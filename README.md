# Fitting the topology of synthetic particle systems with a novel graph representation

This repository contains the implementation for our work "Fitting the topology of synthetic particle systems via a novel graph representation" ([doi:10.1016/j.commatsci.2026.115251](https://doi.org/10.1016/j.commatsci.2026.115251)).

It provides functionality to compute particle graphs on labeled images of particle systems, optimize their topology against a set of target persistence diagrams, and reconstruct optimized synthetic images with an improved connectivity and higher dimensional topology.

# Installation

Clone this repository and create a virtual python environment. The required packages can be found in the file `requirements.txt` and can be installed in the activated virtual environment with the command

```bash
pip install -r requirements.txt
```

The particle graph computation uses a c++ backend. A compiled binary is found in the `line_interference` folder. However, your system and python installation will likely require you to recompile it. This can be done with the following command:

```bash
cd line_interference
c++ -O3 -shared -std=c++17 -fPIC -fopenmp  $(python3 -m pybind11 --includes)     line_interference.cpp -o line_interference_cpp$(python3.11 -c "import sysconfig; print(sysconfig.get_config_var('EXT_SUFFIX'))")
cd ..
```

The implementation is tested on a Linux system with Python 3.11.11. 

# Content

This repository contains 6 scripts, which can be executed. Hyperparameters for every script can be adjusted at the bottom of the scripts. The function `load_images_from_scratch` loads an image from a directory containing a tif stack as individual 2d images. Please exchange the function with an image loading function suiting your data. We now briefly describe what every script is doing.

The 6 executable scripts are:

`compute_3d_graph.py`
Computes the graph with a specific threshold for a specified image and stores it to an output folder.

`compute_reconstructions.py`
Computes and stores the reconstructions for a set of images and graphs as well as prints the metrics from section "Validation of the Reconstruction Quality".

`evaluate_database.py`
Evaluates a database generated by main_images.py or main_optimization.py and prints the summary statistics from section "Synthetic Images of Concrete".

`generate_rsa.py`
Generates and stores a synthetic image and its downscaled version with RSA from a ground-truth image.

`main_images.py`
Generates a base study for a set of images. For every image it generates a set of synthetic images and setups a database with the topological and image metrics from section "Synthetic Images of Concrete.

`main_optimization.py`
This needs a base study generated from main_images.py. In the following, this script optimizes the graphs for a set of hyperparameters, reconstructs their images, computes their metrics, and store them to a database.
